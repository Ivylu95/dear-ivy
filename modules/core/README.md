# core

The layer that is always on: the blank record, the core skills' blank shapes and
the evidence base
(ARC-006). What it contributes to a new record is named in `module.json`.

| Folder | What it holds |
|---|---|
| [`knowledge/`](knowledge/README.md) | The evidence base: cited practice, the subject list and the research log |
| [`templates/`](templates/README.md) | Blank shapes, one folder per skill that fills them |
