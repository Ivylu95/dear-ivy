# People

One file per person who matters: `firstname.md`. My view of them — not fair,
not balanced, just honest.

Each file:

```
# <Name>

**Who they are to me:**
**Phone:**  (optional — only if it is someone I'd actually call)

## What's good
## What's hard
## What I want from this
## Where it stands  (dated, newest first)
```

**Phone** is optional and exists for one page. The safety plan names the people
I'd reach for; where a number is on file here, that plan shows it as a tap to
call. Written as digits, with or without a `+65` — anything that is not dialable
("through the practice") is left out rather than shown as a number that isn't
one. Nothing else in the dashboard reads it.

A name corrected: copy the page as first written into `data/archive/` first,
then rename it (the `a-person` skill). A rename alone keeps no trace of it.
