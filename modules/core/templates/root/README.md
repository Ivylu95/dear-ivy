# data/

Everything in here is hers. Her words, her history, her record. Nothing outside
this folder holds anything personal.

This file is the map and the index: first which folder holds what, then every
standing file, one line each. One file, so a session reads one short orienting
layer and drops into the detail only for the part it needs.

## The map

The root belongs to the harness: the profile, the safety plan and the archive, which
no module may own. Each module keeps everything of its own in one folder named for it.

| | |
|---|---|
| `PROFILE.yaml` | Who this is for, and the essentials needed before any conversation. Everything else here is prose. |
| `safety/` | Warning signs, what helps, who to call. The safety floor, so the harness's and never a module's. |
| `archive/` | Superseded material. Nothing is deleted — it moves here. |
| `core/` | The core module. Everything from here to the next module is its. |
| `core/timeline.md` | **The spine.** Every dated event, in order — Eras first, then entries. Read after `core/state/now.md`. |
| `core/state/` | Working memory — the current snapshot, the session log, open threads. |
| `core/me/` | Who she is, what she wants, what helps, how to speak to her, patterns she has named. |
| `core/people/` | One per person, named for the name she uses: a page, or a folder with a `README.md` front page once one page isn't enough. Never both. |
| `core/journal/` | Dated entries. |
| `core/calendar/` | What is coming, and the dates that land hard every year. |
| `core/assets/` | Files that are not words. See the note in the folder. |
| `<module>/` | One folder per optional module, named for it. See `modules/README.md` in the harness. |

## The rules are not here

Why this folder is committed rather than ignored, why privacy comes from the
repository being private rather than from holding files out of it, and what a
commit message may name — those are specification, and they live in
[`dev/specs/`](../dev/specs/). Stating them here as well would be a
second copy that disagrees with the first the day one of them changes.

What stays in this file is the map, because a map belongs next to the territory.
