# Archive

Nothing in this repo is ever deleted. Superseded, stale, or consolidated
material moves here as `YYYY-MM_<what>.md`, with a header saying where it came
from and why it moved.

Not everything here is a document. A superseded file from `data/assets/` lands as
`YYYY-MM-DD_avatar.<ext>` — the date it stopped being current. It has no header
to carry its story, so its name is the whole of it.

If you're looking for something that seems to have vanished, it's here.
