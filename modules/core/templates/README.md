# Core templates

Blank shapes, one folder per skill that fills them. Where each one is copied to
is the table in [`.claude/skills/README.md`](../../../.claude/skills/README.md).

| Folder | What it holds |
|---|---|
| [`a-person/`](a-person/) | A new person's page |
| [`root/`](root/README.md) | The record's root, which is the harness's: its map and the archive's note |
| [`blank-record/`](blank-record/README.md) | The core module's folder in a new record, `data/core/` |
| [`first-contact/`](first-contact/) | The standing files a session needs before it can run |
| [`import-data/`](import-data/) | An import's manifest |
| [`journal/`](journal/) | A dated journal entry |
| [`look-it-up/`](look-it-up/) | A knowledge subject's practices file |
| [`pattern-work/`](pattern-work/) | A named pattern |
| [`skill-writer/`](skill-writer/) | A skill's grounding log |
| [`reminders/`](reminders/) | A reminders file, sent by the hourly sweep (`"send": "routine"`) and kept by the reminders skill |
