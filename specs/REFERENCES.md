# References [REF]

Reference, not specification. Nothing here is binding and nothing here can be breached — these are the works that independently corroborate a claim made in one of the registers.

> 🔒 **An agent may not edit this file.** The prohibition extends to any alteration of it, rewording, reformatting, renaming and moving included, and admits no exception for a change the agent judges harmless. Where an agent finds anything wrong, inconsistent or improvable — a dead link, a claim the source no longer supports, a limit that was written too generously — it records the finding in [`REVIEW.md`](REVIEW.md) with its reasoning and leaves the entry for a person to clear. Adding a row is an edit like any other.

## Purpose and Scope

The provisions below fix this file's purpose and the reach of its authority. Unlike every other file in this folder it carries no register, because nothing in it can be true or false of the repository.

| #   | Provision                                        | What it means                                                                                                                                                                                                                                                                       |
| --- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **This file is informative, never normative.**   | A tag is evidential and never binding. It cannot make a statement true, cannot outrank a rationale, and changes nothing about precedence. A rationale exists so a reader can *weigh* a rule; a citation that ends the argument has defeated the column it sits in. |
| 2   | **One file, not a table per register.**          | A source rarely belongs to one family — `NIST-800-92` corroborates the record's integrity in [`ARCHITECTURE.md`](system/ARCHITECTURE.md) and the unattended run's restraint in [`system/maintenance.md`](system/maintenance.md). Copied into both it becomes two entries that drift; **ARC-013** covers the same failure for rows. |
| 3   | **Every row states where it does not reach.**    | A source found while reasoning about something else, in a different field, at a different scale, does not transfer whole. The limit is what keeps a tag honest, and if it cannot be written then there is no source and the tag comes off. |
| 4   | **Every row carries the date it was checked.**   | Nothing in this repository verifies that an external work still says what was claimed of it — `check-links.mjs` reads paths and spec IDs, never meaning. The date is what a reader weighs the claim against. |

A `[KEY]` tag in a register links to the **work itself**, and carries this file's *where it does not reach* line as its hover title. This file is where the full entry lives. How tags are used, and when one should not be written at all, is **Source tags** in [`README.md`](README.md).

**A tag going straight out is a deliberate trade.** The limit is the part that keeps a citation honest, and a reader who follows a tag to NIST or ISO does not pass through it on the way. The hover title is what stands in — shorter than the row below, and it is the reason every tag must carry one.
