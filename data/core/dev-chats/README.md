# dev-chats/

What the developer says about his own life inside a development chat does not stay in
`dev/dialogue/transcript/`: it is moved here, word for word, so nothing personal is left
outside `data/` (A-155). One file a month, `YYYY-MM.md`; each entry sits under
`## T-nnn · <date>`, the Transcript entry it was moved from, which keeps
`[moved to his record]` in its place. Only added to, never rewritten.

Empty in a copy where no development chat has happened.
