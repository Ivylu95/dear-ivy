# Accepted development replies

Real replies the developer accepted, with nothing personal in them, kept as
held-out cases for the reply check (`WKB-005`, *"A change to the reply shape is
judged against replies it did not write."*). `../test-dev-reply.mjs` runs the
check over every `.md` here but this one: each must pass. A change to the shape
that makes one fail is a regression, or a deliberate change, in which case the
fixture is updated in the same commit with the developer's words quoted.
