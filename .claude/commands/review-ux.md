# `/review-ux`

Review the app in `ux/` end to end, or `$ARGUMENTS` if given. The goal: it should be fast, lean and clear — no bottlenecks, no wasted work, nothing redundant, nothing that makes the person reading it stop and wonder. Decide for yourself what matters most and why.

Report findings worst first, with `path:line` and the fix. Don't edit unless asked. If it's already in good shape, say so and stop.
