# `/dev-mode`

Switch this session into development mode, as `DEV-001` requires: *"A session
follows development practice only when the developer has switched it on."*

1. Read [`specs/system/dev.md`](../../specs/system/dev.md) in full. Every row in
   its register binds from now until the session ends. If
   `specs/harness/practice.md` exists, read it too — it holds the rules
   for how an agent makes a change, and development mode loads them with this
   register.
2. Say so in the first reply: one line that development mode is on, then the
   register's rows as ID and statement, read from the file just opened, never
   recalled.
3. Then take up `$ARGUMENTS` if given, or wait.

Development mode adds rules; it lowers none. The safety floor in `CLAUDE.md`
outranks everything this command loads, in this session as in any other.

This file is only the door. What development mode requires lives in the
register, and is read from there each time — `ARC-013`, *"Every fact has one
authoritative home; everything else points to it."*
