# Review queue

Everything the agent observes about the repository but is not allowed to act on. Written by the agent; cleared by a person.

`specs/` is the specification and is not the agent’s to change — see **§ The rules** in [`specs/README.md`](../specs/README.md). This file is where the two rules that follow from that put their output:

- **Deviations** — the repo departs from a row. The spec is right; the repo needs fixing.
- **Proposals** — the row itself may be wrong, or a better design has presented itself. Needs a human decision.

**Findings about the spec files themselves go to [`specs/REVIEW.md`](../specs/REVIEW.md)** — a departure inside `specs/`, a redraft of a row, a paste-ready register line. **An entry lives where its fix lands:** this file when the repository is what is in question, that one when the spec file is. The two were one file until 2026-09-21.

Every entry cites a spec ID. Nothing personal goes in this file.
