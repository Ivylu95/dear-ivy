# components

The React components the routes are built from, one folder per tab or concern.

| Folder | What it holds |
|---|---|
| [`me/`](me/) | The profile photograph and its editor |
| [`shell/`](shell/) | The frame around every page, shared with the admin app in `dev/ui/`: the document, the shell, navigation, profile, rail facts |
| [`ui/`](ui/) | Shared primitives used across tabs |
