# api

Route handlers. Each folder is one endpoint, in `route.js`.

| Folder | What it does |
|---|---|
| [`avatar/`](avatar/) | Reads, saves and removes the profile photograph |
| [`login/`](login/) | Signs in and sets the session cookie |
| [`logout/`](logout/) | Clears the session cookie |
| [`record/`](record/) | Switches between the real record and the sample |
| [`watch/`](watch/) | Streams file changes so open pages reload |
