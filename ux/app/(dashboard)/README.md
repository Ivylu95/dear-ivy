# (dashboard)

Every signed-in page. A route group: the brackets keep it out of the URL. Each
tab is a folder; what each must show is its register in
[`dev/specs/ux/tabs/`](../../../dev/specs/ux/tabs/README.md). The developer's views
(Changes, Workflow, Specs, Harness) are an app of their own in `dev/ui/` (WKB-002).

| [`calendar/`](calendar/) | Calendar |

| [`loops/`](loops/) | Open loops |
